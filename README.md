# Global-Solution1-Python
# MISSION CONTROL AI
Descrição
O Mission Control AI é um sistema desenvolvido em Python para simular o monitoramento de uma missão espacial experimental. O programa analisa dados operacionais ao longo de diferentes ciclos, calcula níveis de risco, identifica tendências da missão, gera recomendações automáticas e apresenta um relatório final com os principais indicadores da operação.

# Objetivo
O projeto tem como objetivo aplicar conceitos fundamentais de programação por meio da simulação de um sistema de controle de missão espacial. Durante a execução, são analisadas informações de temperatura, comunicação, bateria, oxigênio e estabilidade operacional, permitindo a classificação do estado da missão em cada ciclo.

# Funcionamento
A missão é representada por uma matriz chamada dados_missao, onde cada linha corresponde a um ciclo de monitoramento e cada coluna representa uma área monitorada: temperatura, comunicacao, bateria, oxigenio e estabilidade.
Durante cada ciclo, o sistema:
* Analisa os dados da missão;
* Classifica cada variável como NORMAL, ATENÇÃO ou CRÍTICO;
* Calcula a pontuação de risco do ciclo;
* Executa reparos automáticos em sistemas prioritários;
* Gera recomendações operacionais;
* Registra informações para o relatório final.

Além disso, eventos como tempestades solares, falhas de energia, vazamentos de oxigênio e instabilidades de sistema podem ocorrer e afetar os dados da missão por mais de um ciclo.

# Principais Recursos
* Geração automática dos ciclos da missão;
* Sistema de eventos críticos;
* Cálculo de risco por ciclo;
* Classificação automática da missão;
* Sistema de reparo automático com priorização por gravidade;
* Análise da tendência da missão;
* Identificação da área mais afetada;
* Relatório final detalhado.

# Tecnologias Utilizadas
* Python
* Listas e matrizes
* Funções
* Estruturas condicionais
* Estruturas de repetição

# Melhorias Futuras
Algumas melhorias que podem ser implementadas em versões futuras incluem:

# Conclusão
O sistema atende aos requisitos propostos para a atividade, simulando de forma estruturada um ambiente de controle de missão espacial. O projeto permite analisar riscos, monitorar sistemas críticos e aplicar mecanismos automáticos de recuperação, demonstrando a aplicação prática de conceitos fundamentais de programação.
